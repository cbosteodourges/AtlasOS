# Atlas OS — Genesis 4.3.0

## Import Garmin dans le moteur Physiologie

- centre d’import par glisser-déposer ;
- import de plusieurs fichiers ;
- lecture des CSV Garmin en français et en anglais ;
- détection automatique de la virgule, du point-virgule ou de la tabulation ;
- gestion des nombres français et anglais ;
- reconnaissance :
  - date ;
  - activité ;
  - distance ;
  - durée ;
  - fréquence cardiaque moyenne et maximale ;
  - allure ;
  - dénivelé ;
  - cadence ;
- import et export JSON Atlas ;
- détection des fichiers FIT et ZIP ;
- stockage local dans le navigateur ;
- calcul :
  - nombre d’activités ;
  - distance et durée totales ;
  - volume sur 28 jours ;
  - volume hebdomadaire sur 8 semaines ;
  - plus longue sortie ;
  - FC maximale observée ;
  - allure moyenne de course ;
  - indice de confiance selon les données disponibles ;
- tableau des dernières activités ;
- CSV Garmin de démonstration inclus.

## Limites de cette version

- les fichiers FIT sont détectés mais pas encore décodés ;
- le ZIP d’export complet Garmin n’est pas encore extrait ;
- les données de sommeil, VFC, stress et Body Battery seront ajoutées ensuite.
