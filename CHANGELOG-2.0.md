# Atlas OS — Genesis 2.0.0

## Module Performance & Running

- choix de l’épreuve ;
- choix de la date exacte ;
- VMA, FCmax et FCrepos ;
- zones 1 à 5 avec :
  - pourcentage de FCmax ;
  - valeurs en BPM ;
  - pourcentage de VMA ;
  - vitesse en km/h ;
  - allure en min/km ;
- SV1 placé après la Zone 2 ;
- SV2 placé après la Zone 3 ;
- distinction entre seuils estimés et seuils mesurés ;
- plan complet daté jusqu’à l’échéance ;
- chaque séance contient :
  - jour et date ;
  - objectif physiologique ;
  - zone ;
  - BPM ;
  - % FCmax ;
  - % VMA ;
  - vitesse ;
  - allure ;
- mode d’affichage FC, vitesse ou hybride ;
- adaptation au nombre de jours d’entraînement ;
- impression / export PDF via le navigateur.
